# BrightSteps Care & Development Centre — redesigned

## Run locally
1. Extract this folder.
2. Open the extracted `BrightSteps_Care_Development_Centre` folder in VS Code.
3. In the terminal run `npm install` and then `npm run dev`.
4. Open the local URL printed by Vite.

## Included
- Refined teal, warm ivory and coral theme with responsive navigation.
- Dedicated Residential Care page at `/residential-care`.
- Residential care information is phrased as a service overview; confirm actual availability, eligibility and clinical provisions before publishing.
- Uses remote Unsplash images, so internet access is needed for those images.

Replace the demo phone number, address and email in `src/components/Layout.jsx` before publishing.
